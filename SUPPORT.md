# Getting help

- **Documentation:** <https://sparkz400.github.io/network-scope/> (source in [docs/src](docs/src/SUMMARY.md)), including [FAQ and troubleshooting](docs/src/faq.md).
- **Questions and ideas:** [GitHub Discussions](https://github.com/Sparkz400/network-scope/discussions). Use the Q&A category for "how do I…" questions and Ideas for suggestions.
- **Bugs:** [open an issue](https://github.com/Sparkz400/network-scope/issues/new/choose) with the bug report template.
- **Device or protocol support:** use the protocol support issue template.
- **Security issues:** never in public; see [SECURITY.md](SECURITY.md).

Before posting logs, screenshots or exports, redact IP addresses, MAC addresses and host names.

This is a volunteer project; there is no commercial support and no guaranteed response time.
