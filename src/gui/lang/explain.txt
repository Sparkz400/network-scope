# "Explain this" texts of the findings (ROADMAP F41): what a finding means for someone who is
# not a network specialist, why it matters and what to do, in one to three sentences.
# One entry per line: "rule id || English || Deutsch". The rule id is the name of the finding's
# documentation page in docs/src/findings (cve-* and script-* findings share cve-hints and
# script-findings). A test checks that every page has an entry here in both languages and that
# no entry is left without a page. The full text is on the "Learn more" page.

cve-cve-2020-0796 || This Windows computer looks like a version with "SMBGhost", a known flaw in file sharing that lets an attacker take over the machine over the network. Install the Windows updates from March 2020 or later. || Dieser Windows-Rechner scheint eine Version mit „SMBGhost“ zu haben, einer bekannten Lücke in der Dateifreigabe, über die ein Angreifer den Rechner übers Netz übernehmen kann. Installieren Sie die Windows-Updates ab März 2020.
cve-hints || The software version this device reports is on a list of versions with a publicly known security flaw. Vendors sometimes fix flaws without changing the version number, so check with the vendor and install the current update. || Die Softwareversion, die dieses Gerät meldet, steht auf einer Liste von Versionen mit einer öffentlich bekannten Sicherheitslücke. Hersteller beheben Lücken manchmal ohne neue Versionsnummer; prüfen Sie es beim Hersteller und installieren Sie das aktuelle Update.
docker-api || The control interface of Docker, a tool that runs programs in containers, can be reached over the network. Whoever can use it can run any program on this machine; allow access only over a protected, authenticated connection or switch it off. || Die Steuerschnittstelle von Docker, einem Werkzeug, das Programme in Containern ausführt, ist übers Netz erreichbar. Wer sie nutzen kann, kann auf diesem Rechner beliebige Programme starten; erlauben Sie den Zugriff nur über eine geschützte, angemeldete Verbindung oder schalten Sie sie ab.
ftp-cleartext || This device offers file transfer over FTP, which sends passwords and files unencrypted, so anyone listening on the network can read them. Use an encrypted method such as SFTP or FTPS instead and switch plain FTP off. || Dieses Gerät bietet Dateiübertragung per FTP an; dabei gehen Passwörter und Dateien unverschlüsselt über das Netz und können mitgelesen werden. Nutzen Sie stattdessen ein verschlüsseltes Verfahren wie SFTP oder FTPS und schalten Sie einfaches FTP ab.
heartbleed || The web server reports an encryption library version with "Heartbleed", a well-known flaw that lets outsiders read secrets such as passwords and keys from its memory. Update the software, then replace the server's certificate and passwords. || Der Webserver meldet eine Version der Verschlüsselungsbibliothek mit „Heartbleed“, einer bekannten Lücke, über die Fremde Geheimnisse wie Passwörter und Schlüssel aus dem Speicher lesen können. Aktualisieren Sie die Software und tauschen Sie danach Zertifikat und Passwörter aus.
http-basic-cleartext || A web page asks for a user name and password over an unencrypted connection, so anyone on the network can read them. Use HTTPS for this page. || Eine Webseite fragt Benutzername und Passwort über eine unverschlüsselte Verbindung ab, sodass jeder im Netz sie mitlesen kann. Stellen Sie die Seite auf HTTPS um.
ldap-anonymous || A directory service (the address book of users and computers, such as Active Directory) answers without a login. Outsiders can learn user names and the structure of the network from it; turn off anonymous access. || Ein Verzeichnisdienst (das Adressbuch der Benutzer und Rechner, etwa Active Directory) antwortet ohne Anmeldung. Fremde können daraus Benutzernamen und den Aufbau des Netzes erfahren; schalten Sie den anonymen Zugriff ab.
mail-cleartext || A mail server accepts connections without encryption, so mail programs may send passwords and messages readable on the network. Require encrypted connections (TLS). || Ein Mailserver nimmt Verbindungen ohne Verschlüsselung an; Mailprogramme senden Passwörter und Nachrichten dann lesbar über das Netz. Verlangen Sie verschlüsselte Verbindungen (TLS).
memcached-open || A cache server answers anyone without a password, so its stored data can be read and changed. Make it listen only on the machine itself or the internal network and block the port in the firewall. || Ein Cache-Server antwortet jedem ohne Passwort, seine gespeicherten Daten können gelesen und verändert werden. Lassen Sie ihn nur auf dem Rechner selbst oder im internen Netz lauschen und sperren Sie den Port in der Firewall.
mqtt-anonymous || A message hub used by smart devices and gateways accepts connections without a login. Anyone on the network can read the messages and send fake commands; require a user name and password. || Ein Nachrichtenverteiler, den smarte Geräte und Gateways nutzen, nimmt Verbindungen ohne Anmeldung an. Jeder im Netz kann die Nachrichten lesen und falsche Befehle senden; verlangen Sie Benutzername und Passwort.
netbios-ns || The device answers an old Windows name service and tells anyone its computer name and network group. That helps attackers map the network; switch NetBIOS off where it is not needed. || Das Gerät antwortet auf einen alten Windows-Namensdienst und verrät jedem Rechnernamen und Netzwerkgruppe. Das hilft Angreifern, das Netz zu erkunden; schalten Sie NetBIOS ab, wo es nicht gebraucht wird.
ot-control-traffic || Commands that change an industrial device (write values, load a program, start or stop it) were seen on the network. Make sure the sending machines are the ones that are supposed to control this device. || Im Netz wurden Befehle gesehen, die ein Industriegerät verändern (Werte schreiben, Programm laden, starten oder stoppen). Prüfen Sie, ob die sendenden Rechner dieses Gerät wirklich steuern sollen.
ot-reachable || An industrial control port is reachable from where the scan ran, and such protocols usually have no password or encryption. Whoever reaches it may be able to read or change the process; restrict access with a firewall to the machines that need it. || Ein industrieller Steuerungs-Port ist von dort erreichbar, wo der Scan lief, und solche Protokolle haben meist weder Passwort noch Verschlüsselung. Wer ihn erreicht, kann den Prozess womöglich lesen oder verändern; beschränken Sie den Zugriff per Firewall auf die Rechner, die ihn brauchen.
php-eol || The website runs on a PHP version that no longer gets security fixes. New flaws will stay open; update to a supported PHP version. || Die Website läuft mit einer PHP-Version, die keine Sicherheitsupdates mehr bekommt. Neue Lücken bleiben offen; aktualisieren Sie auf eine unterstützte PHP-Version.
postgres-no-tls || A PostgreSQL database cannot encrypt its connections, so data and possibly passwords cross the network readable. Turn on TLS in the database settings. || Eine PostgreSQL-Datenbank kann ihre Verbindungen nicht verschlüsseln; Daten und unter Umständen Passwörter gehen lesbar über das Netz. Schalten Sie TLS in den Einstellungen der Datenbank ein.
rdp-no-nla || Remote Desktop on this computer lets people connect before they have proved who they are. That makes password guessing and attacks on the sign-in screen easier; turn on Network Level Authentication. || Remotedesktop auf diesem Rechner lässt Verbindungen zu, bevor sich jemand ausgewiesen hat. Das erleichtert Passwortraten und Angriffe auf den Anmeldebildschirm; schalten Sie die Authentifizierung auf Netzwerkebene (NLA) ein.
redis-noauth || A Redis database answers anyone without a password, so its data can be read and changed, and often the whole server can be taken over. Set a password and make it reachable only from the machines that need it. || Eine Redis-Datenbank antwortet jedem ohne Passwort; ihre Daten können gelesen und verändert und oft der ganze Server übernommen werden. Setzen Sie ein Passwort und machen Sie sie nur für die Rechner erreichbar, die sie brauchen.
script-findings || A check script that you or your organisation added reported this, not the program itself. The script's title and evidence say what it found; ask whoever wrote the script what to do. || Ein Prüfskript, das Sie oder Ihre Organisation hinzugefügt haben, meldet das, nicht das Programm selbst. Titel und Nachweis des Skripts sagen, was es gefunden hat; fragen Sie den Autor des Skripts, was zu tun ist.
smb-no-encryption || The file-sharing server cannot encrypt its traffic, so file names and contents can be read on the network. Use a current SMB version and turn on encryption for sensitive shares. || Der Dateiserver kann seinen Datenverkehr nicht verschlüsseln; Dateinamen und Inhalte können im Netz mitgelesen werden. Nutzen Sie eine aktuelle SMB-Version und schalten Sie die Verschlüsselung für sensible Freigaben ein.
smb-signing || The file-sharing server does not insist on signed messages, so an attacker in between can change traffic or pass on stolen logins. Require SMB signing. || Der Dateiserver besteht nicht auf signierten Nachrichten; ein Angreifer dazwischen kann den Verkehr verändern oder abgefangene Anmeldungen weiterreichen. Schreiben Sie SMB-Signierung verbindlich vor.
smb1-enabled || The server still speaks SMB version 1, the outdated Windows file-sharing protocol that well-known ransomware spread through. Switch SMB1 off; current systems use SMB 2 or 3. || Der Server spricht noch SMB Version 1, das veraltete Windows-Dateifreigabeprotokoll, über das sich bekannte Erpressersoftware verbreitet hat. Schalten Sie SMB1 ab; aktuelle Systeme nutzen SMB 2 oder 3.
snmp-public || The device answers monitoring queries with the factory password "public", so anyone can read its configuration and sometimes change it. Change the password or, better, use SNMP version 3 with a login. || Das Gerät beantwortet Überwachungsabfragen mit dem Werkspasswort „public“; jeder kann seine Konfiguration lesen und manchmal ändern. Ändern Sie das Passwort oder nutzen Sie besser SNMP Version 3 mit Anmeldung.
ssh-legacy-algorithms || The SSH server (remote login) still offers older encryption methods that are no longer recommended but not broken. Remove them from the server configuration when all clients support newer ones. || Der SSH-Server (Fernanmeldung) bietet noch ältere Verschlüsselungsverfahren an, die nicht mehr empfohlen, aber nicht gebrochen sind. Entfernen Sie sie aus der Serverkonfiguration, sobald alle Clients neuere unterstützen.
ssh-protocol-1 || The remote-login service still speaks SSH version 1, which has serious design flaws. Switch version 1 off and use only version 2. || Der Fernanmeldedienst spricht noch SSH Version 1, die schwere Konstruktionsfehler hat. Schalten Sie Version 1 ab und nutzen Sie nur Version 2.
ssh-weak-algorithms || The SSH server (remote login) offers encryption methods that are considered broken, and a client may end up using one. Remove them from the server configuration. || Der SSH-Server (Fernanmeldung) bietet Verschlüsselungsverfahren an, die als gebrochen gelten, und ein Client könnte eines davon nutzen. Entfernen Sie sie aus der Serverkonfiguration.
telnet-open || The device offers Telnet remote login, which sends everything including passwords unencrypted. Switch Telnet off and use SSH instead. || Das Gerät bietet Fernanmeldung per Telnet an; alles, auch Passwörter, geht unverschlüsselt über das Netz. Schalten Sie Telnet ab und nutzen Sie stattdessen SSH.
tls-3des || The server still allows the old 3DES encryption, parts of which can be recovered in long sessions. Turn 3DES off in the server's TLS settings. || Der Server erlaubt noch die alte 3DES-Verschlüsselung, von der in langen Sitzungen Teile entschlüsselt werden können. Schalten Sie 3DES in den TLS-Einstellungen des Servers ab.
tls-broken-cipher || The server agrees to encryption methods that are broken or give no protection at all, so its encrypted traffic may be readable. Turn these methods off in the server's TLS settings. || Der Server lässt Verschlüsselungsverfahren zu, die gebrochen sind oder gar nicht schützen; sein verschlüsselter Verkehr ist dann womöglich lesbar. Schalten Sie diese Verfahren in den TLS-Einstellungen des Servers ab.
tls-cert-expired || The certificate (the service's digital ID card for encrypted connections) has expired, so browsers and devices show warnings or refuse to connect. Install a new certificate. || Das Zertifikat (der digitale Ausweis des Dienstes für verschlüsselte Verbindungen) ist abgelaufen; Browser und Geräte warnen oder verweigern die Verbindung. Installieren Sie ein neues Zertifikat.
tls-cert-expiring || The certificate (the service's digital ID card) expires within 30 days, after which browsers and devices will warn or refuse to connect. Renew it now. || Das Zertifikat (der digitale Ausweis des Dienstes) läuft in den nächsten 30 Tagen ab; danach warnen Browser und Geräte oder verweigern die Verbindung. Erneuern Sie es jetzt.
tls-cert-not-yet-valid || The certificate's start date is in the future, so clients reject it as if it had expired. Check the device's clock and the certificate's dates. || Das Startdatum des Zertifikats liegt in der Zukunft; Clients lehnen es wie ein abgelaufenes ab. Prüfen Sie die Uhr des Geräts und die Daten des Zertifikats.
tls-deprecated-protocol || The server still accepts TLS 1.0 or 1.1, outdated encryption versions that were retired in 2021. Allow only TLS 1.2 and 1.3. || Der Server nimmt noch TLS 1.0 oder 1.1 an, veraltete Verschlüsselungsversionen, die 2021 ausgemustert wurden. Erlauben Sie nur TLS 1.2 und 1.3.
tls-no-pfs || If the server's secret key is ever stolen, traffic recorded today could be decrypted later. Prefer encryption with "forward secrecy" (ECDHE) in the server's TLS settings. || Falls der geheime Schlüssel des Servers je gestohlen wird, ließe sich heute mitgeschnittener Verkehr später entschlüsseln. Bevorzugen Sie in den TLS-Einstellungen des Servers Verfahren mit „Forward Secrecy“ (ECDHE).
tls-self-signed-bad-signature || The certificate claims to have signed itself, but the signature does not match, so it was damaged, altered or forged. Find out where it came from and replace it. || Das Zertifikat gibt an, sich selbst unterschrieben zu haben, aber die Unterschrift passt nicht; es wurde beschädigt, verändert oder gefälscht. Klären Sie seine Herkunft und ersetzen Sie es.
tls-self-signed || The certificate was signed by the device itself rather than by a trusted authority, so clients cannot tell a genuine server from an impostor. Use a certificate from your organisation's or a public certificate authority. || Das Zertifikat hat das Gerät selbst unterschrieben statt einer vertrauenswürdigen Stelle; Clients können den echten Server nicht von einem Betrüger unterscheiden. Nutzen Sie ein Zertifikat Ihrer Organisation oder einer öffentlichen Zertifizierungsstelle.
tls-sslv3 || The server still accepts SSL 3.0, an encryption protocol from 1996 that has long been broken. Switch it off and allow only TLS 1.2 and 1.3. || Der Server nimmt noch SSL 3.0 an, ein Verschlüsselungsprotokoll von 1996, das seit Langem gebrochen ist. Schalten Sie es ab und erlauben Sie nur TLS 1.2 und 1.3.
tls-weak-key || The certificate's key is too short and can be broken with far less effort than current keys. Replace it with a certificate with at least a 2048-bit key. || Der Schlüssel des Zertifikats ist zu kurz und lässt sich mit viel weniger Aufwand brechen als heutige Schlüssel. Ersetzen Sie es durch ein Zertifikat mit mindestens 2048 Bit.
tls-weak-signature || The certificate is signed with an outdated method (MD5 or SHA-1) that can be forged. Replace it with a certificate signed with SHA-256 or better. || Das Zertifikat ist mit einem veralteten, fälschbaren Verfahren (MD5 oder SHA-1) unterschrieben. Ersetzen Sie es durch ein mit SHA-256 oder besser unterschriebenes Zertifikat.
upnp-exposed || The device answers UPnP, a service that lets programs find devices and, on routers, open firewall ports by themselves. Switch UPnP off where it is not needed, and never allow it from the internet. || Das Gerät antwortet auf UPnP, einen Dienst, mit dem Programme Geräte finden und auf Routern selbstständig Firewall-Ports öffnen können. Schalten Sie UPnP ab, wo es nicht gebraucht wird, und nie aus dem Internet erreichbar.
vnc-exposed || A VNC remote-desktop service answers, which gives full control of the screen, keyboard and mouse. Make sure it needs a strong password and is reachable only from where it is needed, ideally through a VPN. || Ein VNC-Fernzugriffsdienst antwortet, der volle Kontrolle über Bildschirm, Tastatur und Maus gibt. Sorgen Sie für ein starkes Passwort und erreichbar nur von dort, wo er gebraucht wird, am besten über VPN.
