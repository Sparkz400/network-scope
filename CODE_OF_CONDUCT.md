# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. All participants in issues, discussions, pull requests and other project spaces are expected to follow it.

## Reporting

To report unacceptable behaviour, contact the maintainer privately through GitHub: use the "Report content" option on the comment or issue, or open a private report at <https://github.com/Sparkz400/network-scope/security/advisories/new> and state that it concerns the code of conduct. Reports are handled confidentially.

Enforcement follows the Enforcement Guidelines of the Contributor Covenant 2.1.
